# Proyecto-final-Frontend
Este es el proyecto final para el curso de Frontend, consistente en una tienda virtual interactiva que consume la **Fake Store API**. La aplicación permite a los usuarios buscar productos por ID, visualizarlos dinámicamente y gestionar un carrito de compras.

## 🚀 Características

- **Consumo de API:** Obtención de datos en tiempo real desde [FakeStoreAPI](https://fakestoreapi.com/).
- **Búsqueda Dinámica:** Interfaz para buscar productos específicos mediante su ID (1-20).
- **Carrito de Compras:** 
    - Añadir productos al carrito.
    - Eliminar productos individualmente.
    - Cálculo automático del total.
    - Persistencia de datos mediante `localStorage`.
- **Interfaz de Usuario Moderna:**
    - Diseño responsivo utilizando **Tailwind CSS**.
    - Notificaciones visuales con **SweetAlert2**.
    - Efectos de celebración con **tsparticles/confetti** al encontrar un producto.
    - Animaciones y transiciones suaves.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica del sitio.
- **Tailwind CSS:** Framework de utilidades CSS para el diseño y estilizado.
- **JavaScript (ES6+):** Lógica del lado del cliente, manipulación del DOM y manejo de peticiones asíncronas (Async/Await).
- **Fake Store API:** Fuente de datos para los productos.
- **SweetAlert2:** Alertas personalizadas.
- **tsparticles confetti:** Efectos visuales de partículas.

## 📦 Instalación y Uso

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/Proyecto-final-Frontend.git
   ```

2. **Abrir el proyecto:**
   Simplemente abre el archivo `index.html` en tu navegador o utiliza una extensión como "Live Server" en VS Code para una mejor experiencia.

3. **Uso:**
   - Navega por las secciones (Inicio, Nosotros, Producto-API, Contacto).
   - En la sección **Producto-API**, ingresa un número del 1 al 20 y haz clic en "Buscar".
   - Haz clic en "Añadir" para sumar productos al carrito.
   - Revisa tu carrito al final de la página y gestiona tus compras.
